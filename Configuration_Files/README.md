## ClearPath Servo Motor Configuration Files
### :warning: Caution! :warning:
These configuration files are intended to allow you to bootstrap a ClearPath servo that has failed, had it's EEPROM erased, or has been salvaged from another machine.

Flashing the incorrect configuration files to your ClearPath servo is possibly the easiest way to render it inopperable. If
your machine is still under warranty, **please** contact Tormach tech support (https://tormach.com/support) and
we can work on your issue with you.

If you would prefer to get a ClearPath servo pre-loaded with the correct configurations for your machine from Tormach, the part numbers are as follows:

| Tormach PN | Description |
| ----- | --------------------- |
| 38406 | X-Axis Servo Motor, 770 |
| 38402 | Y-Axis Servo Motor, 770 |
| 38407 | Z-Axis Servo Motor, 770 |
